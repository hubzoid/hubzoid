# proposals/

Non-trivial changes to Hubzoid start here as **text, not code**.

Write what you want to change and why, in plain language, in a markdown file, and
open a PR with just that file. We discuss it in the PR, and once it's agreed we
(or an agent) implement it. This keeps the codebase thin and lets non-developers
shape Hubzoid.

## How

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `proposals/YYYY-MM-DD-<slug>.md`.
2. Fill it in. A thin idea with honest gaps is fine — better than an inflated one.
3. Open a PR with only that file. Title: `proposal: <what it is>`.

The [`propose-change`](../skills/propose-change.md) skill will do all of this
with you if you point a coding agent at it.

Small, obvious fixes don't need a proposal — just open a PR (see
[`CONTRIBUTING.md`](../CONTRIBUTING.md)).
