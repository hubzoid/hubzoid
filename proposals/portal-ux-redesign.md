# Agent-first administration

Status: implemented in 1.0.1. The Admin Console has changed since this proposal.
See [ADMINISTRATION.md](../docs/ADMINISTRATION.md) and
[access-management.md](../docs/access-management.md) for current behavior.

User-approved direction: keep existing authorization and execution services; replace the backend-shaped portal with an agent-first experience using Ant Design. Begin with agent access, staged capability edits and review before Save, URL navigation and explicit account/access states. Preserve role checks, inherited permissions and multi-hub isolation. Follow with People details, readable Activity and workflow observability.
